# BOLT // MARAKULIN TOWER: 2026

Браузерный **3D-шутер от первого лица (FPS)** на **TypeScript + Vite + Three.js** в неоновом киберпанк-стиле — **приквел к Bolt 2**, рассказывающий историю судьбы Самира в 2026 году (до того, как он стал цифровым конструктом на биочипе в открытом мире *Bolt 2*).

## Сюжет

2026 год. Главный герой **Самир**, вооружённый тяжёлым пистолетом **Malorian S-3516** и имплантом замедления времени **Сандевистан**, в одиночку штурмует небоскрёб **Маракулин Тавер**, чтобы добраться до злостного корпората **Родиона**:

1. **Сектор 01 — Главный Атриум**: вход в башню, голозвонок Родиона, перестрелка с корпо-охраной и дронами.
2. **Сектор 02 — Серверный узел**: нетраннеры (перегрев имплантов), потолочные турели, взлом лазерного барьера через терминал.
3. **Сектор 03 — Предбанник Зала Совета**: панорамный вид на ночной мегаполис, элитные штурмовики и массивные двери **«ЗАЛ СОВЕТА // РОДИОН»**.
4. **Засада — Рихард Смэшер**: прямо перед дверями Родиона героя отбрасывает трёхметровый киборг-босс **Рихард Смэшер**. Двухфазная битва (автопушка, телеграфированные микроракеты, Sandevistan-рывки и ударные волны) завершается тяжёлым ранением Самира и потерей сознания.
5. **Финал — Операционный стол и «Душегуб»**: Самир просыпается на операционном столе. **Родион** произносит монолог с биочипом в руках (доступен интерактивный выбор реплики) и запускает **«Душегуб» (Soulkiller)**, превращая Самира в цифровой конструкт — завязка к **Bolt 2**.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` | Передвижение |
| `Мышь` | Обзор (Pointer Lock) |
| `ЛКМ` | Выстрел из Malorian S-3516 |
| `ПКМ` | Прицеливание (удержание) |
| `R` | Перезарядка |
| `F` / `V` | Огненный ближний удар Malorian |
| `Shift` | Рывок (Dash) |
| `Space` | Прыжок (перепрыгивание ударных волн) |
| `Q` | Сандевистан (замедление времени) |
| `X` | Ингалятор MaxDoc (лечение + броня) |
| `E` | Взлом терминала / ящики с припасами |
| `1` / `2` | Выбор реплики в финальной сцене с Родионом |
| `Esc` | Пауза и настройки (чувствительность мыши, громкость) |
